# QuantumCoin Telegram Space Miner - Cinematic Assets

Bu yapı video-led cinematic intro sistemi için hazırlandı.

## Ana Hedef

Oyunun açılışında sinematik bir giriş olacak:

1. QuantumCoin 360 derece dönen logo
2. Uzayda gemi geçişi
3. İngilizce kısa kokpit konuşması
4. Ay / mining zone tanıtımı
5. Mevcut oyun ekranına geçiş
