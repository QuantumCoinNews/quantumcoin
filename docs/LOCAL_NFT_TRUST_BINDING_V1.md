## This wave

Adds a private NFT authority binding field to Blockchain and three Go files.
The binder validates scope/key/quorum shape, compares the trusted local network and real local genesis, deep-copies authority keys, and binds exactly once under the chain lock.
Approval validation accepts record, decision and signatures; it has no submitted trust argument. A valid signature from a self-declared peer authority cannot replace locally bound authorities.
Policy is private runtime state, excluded from gob and disk serialization. A decoded/loaded chain is unbound and needs explicit binding from trusted local bootstrap. Invalid binding does not consume the one-time slot. Concurrent binding/read tests require one successful publication.

Validation of policy shape does not authenticate a program release or decide production authorities. The caller must obtain network/policy from trusted local configuration. No peer/P2P path or node bootstrap is changed to call the binder in this wave. No real admin keys are chosen or generated by the script; test keys are ephemeral. No global mutable authority registry is used.

This is new functionality: capability tests are used, not a fabricated existing-code RED. Existing mint and NFT block admission remain closed even after valid approval verification. The Blockchain change is restricted to one private struct field; code outside the struct is checked unchanged.
