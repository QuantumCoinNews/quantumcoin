# README graphics

This directory contains the QuantumCoin documentation cover, section banners
and ecosystem map. The graphics use the project's cyan, gold and violet palette.

The SVG files are self-contained vector illustrations with text alternatives,
system-font fallbacks and no scripts or external image/font dependencies.
Edit the SVG text and shapes when the corresponding product section changes.

The root README also displays the existing project logo and Moon environment
asset from their original repository locations. Documentation graphics do not
change the game, token contracts, chain state or NFT catalog.
